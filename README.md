# advent of code
A workspace for advent of code.
This repo contains folders representing each year of Advent of Code.
Each year contains separate folders for each day, themselved containing solutions and any other files, such as text inputs.
Since there are multiple problems for each day, there are multiple solutions in each day's folder.

This repo was created on 24/11/2025, with retroactive work being done on previous years' problems alongside 2025 and in to the future
